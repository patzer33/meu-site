# História do Palmeiras

Site desenvolvido como projeto escolar durante as aulas de Desenvolvimento de Sistemas.

## 📖 Sobre o projeto

O projeto tem como objetivo apresentar a história do Palmeiras, abordando informações sobre a origem do clube, sua trajetória no futebol, mascotes, títulos, jogadores e outros momentos importantes de sua história.

## 🎯 Objetivo

Praticar os conhecimentos de HTML aprendidos em sala de aula, desenvolvendo uma página web com estrutura organizada e conteúdo sobre o Palmeiras.

## 🛠️ Tecnologias utilizadas

* HTML5

